# 0.5.0 App 介面整理

## 問題與導覽

原首頁把預覽、登入、同步、提醒、進階連線與長篇說明放在同一條滾動頁面，所有按鈕同等強調，使用者難以找到要操作的功能。

新導覽固定三個底部分頁，不依賴手勢或隱藏選單：

| 分頁 | 優先內容 | 下一步 |
| --- | --- | --- |
| 總覽 | 兩個服務各自的剩餘額度、重置與資料時間 | 立即更新；未連接時引導連接 |
| 使用計劃 | Claude／Codex 各自的 5 小時／每週計劃 | 點一個時段編輯；另有通知入口 |
| 設定 | 資料連線、更新頻率、通知與資料管理 | 進入對應對話框或頁面 |

桌面小工具的圓環呈現維持原樣，預覽改由總覽的「桌面小工具」開啟。App 總覽改用可滾動的文字與進度條，沒有固定高度的 RemoteViews 卡片限制。

## 層級與操作

- 使用既有深色、薄荷綠與 Claude 橘色；保持原生系統字體，不引入第三方 UI 依賴。
- 主要操作使用實心薄荷綠按鈕；設定項使用標題與次要說明分層的整列入口；內文保持較低視覺權重。
- 觸控區最少 52 dp，分頁等寬，內容以垂直捲動適應窄螢幕。底部分頁和編輯頁儲存列獨立佔位，不覆蓋捲動內容。
- 計劃編輯保留分配方式切換；星期與保留欄位只在選中時出現。數字與標籤同列，表單有可關聯的標籤及欄位錯誤。
- 進階連線預設收起。分頁切換保留欄位輸入與各頁滾動；旋轉時儲存所選分頁及進階區展開狀態。密碼不保存至 Activity 的狀態快照。
- 未儲存的計劃編輯仍有放棄確認；首頁從其他分頁按返回，先回到總覽。
- Codex 登入分為取得代碼、官方網頁授權、返回 App 確認三張卡片。保留加密、私密畫面旗標與原授權行為。
- 不遷移或清空任何額度／登入／計劃／提醒儲存。通知的深層連結仍開啟對應計劃。

## 驗證範圍

本機完成原生 Java／資源／DEX／APK 編譯、版本與簽章檢查。對照程式檢查主要入口、返回、空資料及讀取失敗狀態。主文字、次要文字及主要按鈕文字使用既有高對比色。

尚無連接的 Android 裝置或模擬器，因此不將下列項目標記為已通過：

1. 320–375 dp 手機、橫向及最大字體下，分頁、數字列、對話框、小工具預覽是否完整可用。
2. 真機底部手勢區、鍵盤與固定儲存列的間距，錯誤欄位是否能捲動到可見位置。
3. TalkBack 的標籤、分頁選取狀態與焦點順序；實際觸控及硬體返回。
4. 安裝覆蓋後既有登入與設定正常顯示；三分頁之間切換、離開編輯及通知點入。

沒有產生模擬截圖來代替真機畫面。設計依 UI/UX Pro Max 的內容優先、表單標籤、觸控大小與固定導覽原則，沿用本專案的色彩與原生元件。
