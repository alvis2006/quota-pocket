## 3. 主片完整旁白

以下每段對應上方同編號分鏡。錄音時只唸內文，不唸段落標題。

### 01｜開場

用 Claude 或 Codex 的時候，你會不會想知道，自己還剩多少額度？

這個 Android 小工具叫「額度口袋」，可以把剩餘額度放到手機桌面，也能幫你安排使用計劃。

### 02｜一眼看懂

打開 App，總覽會分別顯示 Claude 和 Codex 的額度。

這裡的百分比代表「還剩多少」，下面可以看到重置倒數和資料更新時間。查看用量時，記得一起確認資料是不是最新的。

### 03｜三個分頁

底下只有三個分頁。

「總覽」用來看額度，「使用計劃」用來安排用量，「設定」則管理連線、更新方式和通知。

接下來，我們先連接資料。

### 04｜連接 Codex

在設定裡點選 Codex，產生登入代碼，再到官方網頁完成授權。

授權完成後回到 App，按下「我已完成授權，連接帳號」。

連接成功後，手機就能直接讀取 Codex 額度，不需要電腦持續開機。這項連接目前是實驗功能。

### 05｜連接 Claude

Claude 的方式不同，目前是讀取額度檔案。

先讓電腦上的 Claude Code 匯出額度，存進雲端同步資料夾。再到 App 的設定，點 Claude，選取這份檔案。

之後手機會重新讀取它；但要先有電腦匯出的新資料，手機上的 Claude 額度才會更新。

### 06｜加到桌面

資料連接好後，回到總覽，點「桌面小工具」，再按「加入桌面」。

小工具的外圈代表五小時額度，內圈代表每週額度；中間的數字，顯示兩者剩得比較少的那一個。

回到桌面，就能快速查看。

### 07｜平均分配

如果你想安排使用節奏，可以打開「使用計劃」。

Claude 和 Codex 的五小時、每週額度，都能分別設定。

先從預設的「平均分配」開始，App 會依照這次額度週期到重置之間的時間，平均安排可用額度。

### 08｜另外兩種計劃

你也可以選「按星期分配」，讓工作日多安排一些，休息日少一些。

或者選「保留額度」。例如設定在距離重置四十八小時前，至少留下百分之三十，之後再安排剩下的用量。

選擇最符合自己習慣的方式就好。

### 09｜偏離提醒

接著，設定用太多或用太少時的提醒門檻。

例如，計劃到現在可以用掉百分之四十，但實際用了百分之五十五，就是超用十五個百分點。

預設偏離十個百分點提醒一次，之後每再偏離十個百分點，才會再次提醒。同一週期內，相同級別不會反覆通知。

這些數字都可以修改，設定好後記得按「儲存計劃」。

### 10｜開啟通知

最後，到「通知設定」開啟用量提醒，並允許手機通知。

提醒預設無聲、不震動；你也可以開啟「額度重置時通知」，等資料來源確認新的額度週期後收到提醒。

按一下「發送無聲測試通知」，就能檢查通知是否正常出現。

### 11｜更新方式

更新方式也能在設定裡調整。

一般背景模式大約每十五分鐘更新，也可以選擇每分鐘模式。實際時間仍可能受到手機省電、網路和資料來源影響，所以不是秒級即時更新。

資料太舊時，App 會暫停用量提醒的判斷。

### 12｜收尾

這就是額度口袋：看剩餘額度、安排使用計劃，偏離時再收到提醒。

如果你也想把 AI 額度放到 Android 桌面，可以從影片說明查看安裝方式。

額度口袋是個人開發的非官方工具，目前介紹的是零點五點零版本。

## 4. 操作字幕與文字卡

這一節適合貼到畫面上，與完整旁白字幕分開使用。每次只出現當下操作需要的一組。

入口字幕：

> 設定 → Codex

步驟卡：

> ① 產生／重新產生代碼  
> ② 複製代碼並開啟官方授權頁  
> ③ 我已完成授權，連接帳號

補充小字：

> 實驗功能・授權成功後可由手機直接更新

### Claude 連接

入口字幕：

> 設定 → Claude → 選擇檔案

步驟卡：

> 電腦上的 Claude Code 匯出額度  
> 將 claude-quota.json 存入雲端同步資料夾  
> 在手機選取同一份檔案

補充小字：

> 需要電腦先產生新資料，手機才會讀到新額度

### 桌面小工具

入口字幕：

> 總覽 → 桌面小工具 → 加入桌面

圖解標籤：

> 外圈｜5 小時額度  
> 內圈｜每週額度  
> 圓心｜兩者之中剩得較少的額度

若系統沒有跳出加入提示，可替換成：

> 長按桌面空白處 → 小工具 → 額度口袋

### 三種使用計劃

入口字幕：

> 使用計劃 → 選服務 → 選額度時段

選項說明：

> 平均分配｜依週期平穩安排  
> 按星期分配｜每天使用節奏不同  
> 保留額度｜先留下一部分，稍後再用

星期比重例子：

> 週一至週五：2  
> 週六、週日：1  
> 2 代表 1 的兩倍比重，不是 2%

保留額度例子：

> 每週額度  
> 距重置前：48 小時  
> 屆時保留額度：30%

### 用量提醒

欄位字幕：

> 超用門檻：10 個百分點  
> 少用門檻：10 個百分點  
> 再次提醒間距：10 個百分點

計算卡：

> 計劃已用 40%  
> 實際已用 55%  
> 超用 15 個百分點

再次提醒卡：

> 偏離 10 → 提醒  
> 偏離 15 → 不增加提醒  
> 偏離 20 → 再提醒  
> 回落後再到 20 → 不重複

補充小字：

> 同一週期、同一方向分別記錄；門檻與間距可自訂

### 啟用通知

入口字幕：

> 設定 → 通知設定

操作提示：

> 開啟「啟用用量提醒」  
> 允許系統通知  
> 選擇是否開啟「額度重置時通知」  
> 按「發送無聲測試通知」

通知示範角標：

> 測試通知・不代表真實用量

### 更新頻率

入口字幕：

> 設定 → 更新頻率

重點卡：

> 一般背景：約 15 分鐘  
> 可選每分鐘模式  
> 請以各服務的資料時間為準

補充小字：

> 每分鐘模式每次約可持續 6 小時，系統也可能提早暫停

### 影片說明欄

我做了一個 Android 額度小工具，叫「額度口袋 Quota Pocket」。

它可以把 Claude 和 Codex 的剩餘額度放在同一個 App 裡，也能加入手機桌面，查看額度、重置倒數和資料更新時間。

## 7. 常見問題文字

可放在影片說明、留言回覆，或剪成補充文字卡。

### 百分比是已使用，還是剩餘？

總覽與桌面小工具顯示的是「剩餘」。計劃比較則使用「已用」，用來計算實際使用量與安排的差距。

### Claude 和 Codex 都不需要電腦嗎？

目前只有 Codex 的手機連接可在授權成功後獨立更新。Claude 仍需要電腦上的 Claude Code 匯出新額度檔案，手機再透過雲端硬碟讀取。

### 為什麼資料沒有馬上更新？

這是定期讀取資料，不是秒級推送。可以先按「立即更新」，並查看各服務的資料時間。Claude 也需要確認電腦上的檔案是否產生新內容。

### 為什麼沒有收到用量提醒？

先確認通知設定中的總開關、系統通知權限，以及該額度時段的監控是否開啟。示範資料、超過一小時的資料或缺少重置時間時，App 不會觸發用量提醒。

### 為什麼倒數到了，卻沒有重置通知？

App 需要取得來源確認的新週期資料，才會發出重置通知。第一次連接資料也不會被當成一次重置。

### 更新 App 需要先卸載嗎？

使用同一簽署金鑰發布的新版 APK，可直接覆蓋安裝。先保留舊版，避免卸載造成登入與設定遺失。
